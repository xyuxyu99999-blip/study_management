# study_management
これは高校の探究活動で作成した勉強管理アプリです。<br>
AIにプログラムをお願いしているので少々見にくい所があるかもしれませんが後々調整していきます。

## これから実装したいこと
・ToDoリストで決めた期限が近づいてきたら通知するようにする<br>
・ホームに期限が近い予定を表示する(要調整)<br>
・webからインストールしてオフラインで使えるようにする(要テスト)<br>
・開発についてをまとめたタブを作る(このサイトに飛べるようにしたり、更新内容を見れるようにする)<br>
・不具合を報告したり、追加してほしい要素を報告できるようにする<br>

## 実装完了したこと
2026/10/09実装<br>
・ToDoリストで完了したタスクをチェックしたあとにタスク完了リストに移動させるようにする<br>
・ToDoリストで期限を決められるようにする<br>
・カレンダーを追加して予定をまとめてに見れるようにする<br>

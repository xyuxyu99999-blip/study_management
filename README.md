# study_management
これは高校の探究活動で作成した勉強管理アプリです。

これから実装したいこと<br>
・ToDoリストで完了したタスクをチェックしたあとにタスク完了リストに移動させるようにする<br>
・ToDoリストで期限を決められるようにして期限が近づいてきたら通知するようにする<br>
・カレンダーを追加して予定をまとめてに見れるようにする<br>
・ホームに期限が近い予定を表示する<br>
・webからインストールしてオフラインで使えるようにする<br>

## オフライン版（PWA）

`pwa/` はブラウザー内にデータを保存するオフライン版です。既存のStreamlit版とはデータを自動同期しません。既存CSVは「データ管理」から読み込み、バックアップは同じ画面から書き出してください。

ローカルで起動する場合:

```bash
python -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開くと、ルートの `index.html` からHTML版へ移動します。一度ページを読み込むと、その後はネットワークがなくても利用できます。インストールするには対応ブラウザーの「インストール」または「ホーム画面に追加」を選んでください。スマートフォンなど別のデバイスへ公開するときは、HTTPSに対応した静的ホスティングを使ってください。

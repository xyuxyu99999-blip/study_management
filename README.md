# study_management
これは高校の探究活動で作成している勉強管理アプリです。<br>
AIアシスタントを使用して制作しているので少々見にくいところがあるかもしれません。<br>

## これから実装したいこと
・ユーザーからの要求やバグの報告をできるようにする<br>
・勉強時間を記録してグラフで表示できるようにする<br>
・テスト結果をグラフで表示できるようにする<br>
・外観(細かいテキストや色味など)の修正をして見やすくする<br>
・設定タブにこのアプリの説明を記述する(githubへのリンクや使用している言語など？)<br>
